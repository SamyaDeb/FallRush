# G4.6: candy palette + grading (agent `palette`, about 2–3 h)

You are the technical artist on **Fall Rush** (Unity 6000.3.28f1 URP, WebGL; code-built maps). You are one of two agents in one session. Obey the shared rules in `docs/prompts/G4.6-G4.7-LEAD.md` §2: one heavy job at a time (in this phase you own Unity), only your own files, no VPS, never push, no new packages, no Fall Guys asset extraction.

## 1. The palette (from the G4 plan page, copied here because the page can't be read from this account)

**Surface hues: every walkable top is coloured**

| Name | Top | Side |
|---|---|---|
| Bubblegum | `#FF6FAE` | `#D8327F` |
| Lemon drop | `#FFD43B` | `#F09A12` |
| Soda blue | `#4CC2FF` | `#1F82E0` |
| Sour apple | `#86E04E` | `#3FA82F` |
| Grape fizz | `#A77DFF` | `#6D3FE0` |
| Tangerine | `#FF9A3D` | `#E05A1F` |

Tops sit at 45–75 % saturation and 85–95 % value, never pure white. Each section gets one hue, so players know where they are. Sides use the same hue, about 20 % darker and more saturated.

**Meaning colours: reserved, never used on a walkable top**

| Meaning | Colour |
|---|---|
| Hit (hits you) | hot pink `#FF2D8A` + an ink stripe |
| About to move | pulsing lemon `#FFD43B` |
| Goal / spring | mint `#2FE0A8` + checker |
| Goo | `#9B3CFF` + glitter |
| Sky | `#2E9BFF` → `#A6E3FF` |

**Grading and lighting**
- Neutral tonemapping, saturation **+22**, contrast **+12**, post-exposure **−0.15**.
- Warm sun, cool sky ambient.
- A rim light on Rushlings and hazards.
- AO baked into the vertex colour, plus a bottom-dark gradient on every prop.
- Outlines: thick ink on characters and hazards, thin on world props, faded with distance (the outline LOD exists).

**Conflicts you must resolve:**
- **Lemon drop = the telegraph yellow.** Use Lemon drop on at most one section per map. Never use it on a section that has a yellow telegraph (Lid Flip's lit lids, gate / belt / chute pulse lights, Star Fountain's crown glow). Never use it on Lid Flip at all.
- **Grape fizz `#A77DFF` is close to goo `#9B3CFF`.** Never use Grape fizz on Goo Tower.
- **Mint is reserved for goal / spring / spawn.** Lid Flip's solid lids are mint today: change them.
- Bubblegum `#FF6FAE` and hit pink `#FF2D8A` must stay apart. Hazards keep the stripe, and no Bubblegum section may hold a hit-pink hazard unless the stripe contrast test passes there.
